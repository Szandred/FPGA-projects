# FPGA-projects
Personal FPGA/verilog projects using a Sipeed Tang Nano 9K.


1-button-counter) The Tang Nano 9k has 6 on-board programmable LEDs and 2 push buttons. As a first project, I wanted to make a 6-bit binary counter. I then scaled it to be a 6-bit binary counter with button 1 acting as a pause/resume and button 2 acting as a reset button.
